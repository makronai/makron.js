Standalone NPM Package • Zero Dependencies

Makron.js

Unified JavaScript & TypeScript Integration Engine for Hosted LLMs, Local Endpoints, Browser Runtimes, and Ecosystem Bridges.

📦 Quick Installation

npm install makron.js

🚀 Autonomous ReAct Agent

import { createAgent, standardTools, createMakron } from 'makron.js';

const ai = createMakron({ provider: 'openai', model: 'gpt-5-mini' });
const agent = createAgent({
  client: ai,
  tools: [standardTools.calculator, standardTools.dateTime],
});

const result = await agent.run('Calculate 45 * 12 and tell me the date');
console.log(result.text);

📚 Plug-and-Play RAG Pipeline

import { createRagPipeline, createMakron } from 'makron.js';

const ai = createMakron({ provider: 'gemini', model: 'gemini-2.5-flash' });
const rag = createRagPipeline({ client: ai });
await rag.addText('Makron.js provides zero-dependency AI engine integration.');

const reply = await rag.query('What does Makron.js provide?');
console.log(reply.answer);
